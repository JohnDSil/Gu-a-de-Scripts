## 🚀 Cómo usar este repositorio

### 1. Clona el repositorio

```bash
git clone https://github.com/tu-usuario/scripts-roadmap.git
cd scripts-roadmap
```

### 2. Comprueba que tienes Python instalado

```bash
python --version
# Deberías ver algo como: Python 3.10.x
```

### 3. Sigue el orden de los niveles

Empieza por `01-basico` y **no saltes niveles**. Cada uno depende del anterior.

### 4. Lee el README de cada carpeta

Cada nivel tiene su propio `README.md` con explicaciones detalladas.

### 5. Ejecuta los scripts de ejemplo

```bash
cd 01-basico/scripts
python 01_hola_mundo.py
```

### 6. Completa los retos

Al final de cada nivel encontrarás retos prácticos. ¡Inténtalos antes de ver la solución!

## 💡 Buenas prácticas que aprenderás

A lo largo del curso irás incorporando estos hábitos profesionales:

- ✅ **Comentar el código** para que otros (y tú mismo en el futuro) lo entiendan
- ✅ **Nombres descriptivos** para variables y funciones
- ✅ **Una tarea = una función** (principio de responsabilidad única)
- ✅ **Manejo de errores** para que los scripts no fallen de forma inesperada
- ✅ **Formato limpio** siguiendo el estilo PEP 8 de Python
